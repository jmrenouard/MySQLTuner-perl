## 🔍 Detailed Ponytail Audit Remediation (Issues 1–17)

| Issue | Category | Description & Surgical Remediation | GitHub Issue |
| :---: | :--- | :--- | :---: |
| **1** | Core SQL / Safety | Removed silent database mutation `SET GLOBAL innodb_stats_on_metadata = OFF` from `check_metadata_perf`, keeping the recommendation in `@adjvars` to uphold the read-only audit contract. | [#1022](https://github.com/major/MySQLTuner-perl/issues/1022) |
| **2** | Shell / Security | Escaped `"`, `` ` ``, and `$` in `select_one` (matching `select_array`), and applied single-quote escaping `s/'/'\\''/g` to `$opt{user}`, `$logfile`, and `$myvar{'log_error'}` in `mysql_setup` and `log_file_recommendations`. | [#1023](https://github.com/major/MySQLTuner-perl/issues/1023) |
| **3** | Process Telemetry | Preserved `$opt{noprocess}` in `setup_environment`, added immediate return 0 in `get_other_process_memory` when active, and excluded `mariadbd` and `garbd` from foreign process memory calculations. | [#1024](https://github.com/major/MySQLTuner-perl/issues/1024) |
| **4** | Windows OS Metrics | Converted Windows `FreeVirtualMemory` from KB to bytes (* 1024), and safely validated swap memory as defined numeric to prevent fatal `memerror` exits on systems with 0 swap. | [#1025](https://github.com/major/MySQLTuner-perl/issues/1025) |
| **5** | InnoDB Storage | Scaled buffer pool page counts by `($myvar{'innodb_page_size'} // 16384)` before calling `hr_bytes()`, and calculated used buffer pool bytes as `(total - free) * page_size` with underflow clamping. | [#1026](https://github.com/major/MySQLTuner-perl/issues/1026) |
| **6** | Auto-Fix / JSON | Excluded read-only variables, sysctl dot keys (`/\./`), and static variables from dynamic `SET GLOBAL` statements in `generate_auto_fix_snippets` and `--agent-json`; implemented comment stripping on target values. | [#1027](https://github.com/major/MySQLTuner-perl/issues/1027) |
| **7** | Windows Portability | Guarded `getpwuid($<)` with `eval` and `$is_win` check in `setup_environment` to prevent fatal exceptions on Windows environments lacking POSIX user databases. | [#1028](https://github.com/major/MySQLTuner-perl/issues/1028) |
| **8** | Query Performance | Preloaded virtual/generated column metadata in a single bulk query in `mysql_80_modeling_checks`, and reused `@engines` in `mysql_databases` to eliminate duplicate `SELECT DISTINCT(ENGINE)`. | [#1029](https://github.com/major/MySQLTuner-perl/issues/1029) |
| **9** | Diagnostic Caching | Scoped and cached query results of `get_pf_memory()` and `get_gcache_memory()` in local variables within `mysql_stats` and `mysql_pfs` to eliminate duplicate queries against Performance Schema. | [#1030](https://github.com/major/MySQLTuner-perl/issues/1030) |
| **10** | System Discovery | Modified `infocmd_tab` to return command output directly in `get_system_info`, avoiding duplicate OS command invocations; removed duplicate `SHOW` queries in `get_all_vars`. | [#1031](https://github.com/major/MySQLTuner-perl/issues/1031) |
| **11** | Kernel / Filesystem | Corrected sysctl recommendation to `fs.nr_open > 1M` and sunrpc threshold display to `< 100` in `get_kernel_info`; fixed mountpoint string interpolation from `$4` to `$5` in `get_fs_info`. | [#1032](https://github.com/major/MySQLTuner-perl/issues/1032) |
| **12** | Galera / Schema | Switched Galera status metrics lookup from `%myvar` to `%mystat`, evaluated `get_wsrep_options()` in list context, computed distinct charsets for `CHARS`, and referenced `$info[3]` for index `TYPE`. | [#1033](https://github.com/major/MySQLTuner-perl/issues/1033) |
| **13** | PFS / Query Cache | Used `AND object_name NOT IN (...)` for `table_io_waits_summary_by_index_usage` queries with `--ignore-tables`; replaced bitwise `|` with logical `||` in `mysql_stats`. | [#1034](https://github.com/major/MySQLTuner-perl/issues/1034) |
| **14** | CLI / Version Update | Preserved `$opt{nocolor} = 1` when `--outputfile` is defined in `setup_environment`; verified downloaded version file size against target path `-s $fullpath` in `update_tuner_version`. | [#1035](https://github.com/major/MySQLTuner-perl/issues/1035) |
| **15** | CSV Dump Export | Checked `unless ($req =~ /\bLIMIT\b/i)` before appending `LIMIT $limit` in `select_csv_file` to prevent duplicate LIMIT clauses. | [#1036](https://github.com/major/MySQLTuner-perl/issues/1036) |
| **16** | Schema Structure | Eliminated redundant foreign key type mismatch query execution in `mysql_table_structures`, relying on dedicated `mysql_foreign_key_checks`. | [#1037](https://github.com/major/MySQLTuner-perl/issues/1037) |
| **17** | Diagnostic Auditors | Wired dormant diagnostic auditors (`audit_pfs_stage_profiling`, `audit_innodb_ahi`, `audit_tls_ciphers_protocols`, `audit_table_definition_cache`) into operational execution safely. | [#1038](https://github.com/major/MySQLTuner-perl/issues/1038) |
